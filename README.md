# Перезагрузка — демоверсия главной

Статическая копия обновлённой главной страницы. Окно записи работает в демонстрационном режиме: заявка не отправляется.

Локальный просмотр из корня репозитория:

    python3 -m http.server 8000 --bind 127.0.0.1

Откройте http://127.0.0.1:8000/. Остальные страницы сайта не включены в эту копию: ссылки на них ведут на действующий сайт.
